## 1. 这个项目在做什么

化学里的"氧化态"是给每个原子记账的一种方式：假想把每条化学键上的电子全部
判给键两端电负性更大的那个原子，然后数一数每个原子比中性状态多了或少了几个
电子。比如 CO2 中，氧比碳更容易吸引电子，所以 C-O 键的电子都记在氧名下，
结果碳记作 +4，氧记作 −2。这个整数虽然是"记账约定"而非可测量的物理量，
但它是化学家描述反应（尤其是氧化还原反应）的通用语言。

问题在于：给定一个量子力学计算（DFT）的结果，**如何自动、可靠地算出每个
原子的氧化态**。电子在真实材料里是弥散的波，不天然属于哪个原子，所以任何
自动判定方案都要回答"这份电子算谁的"。

LEOS（Lattice Effective Oxidation States）是我们的方案，分两部分：

- **VASP 补丁**（Fortran）：在 DFT 计算内部把弥散的电子波变换成一组
  "Wannier 函数"——每个 Wannier 函数是一小团局域化的电子云，正好装两个
  电子（自旋极化时每个自旋通道装一个）。每团电子云有一个明确的中心坐标。
  补丁把这些中心、弥散程度（spread）、占据数等信息写进一个叫 EOSCAR 的
  输出文件。
- **pyleos 包**（Python）：读取 EOSCAR，决定每团电子归属哪个原子，输出
  每个原子的整数氧化态。

直觉图像：Wannier 中心落在某个原子近旁，通常就是那个原子的孤对电子；
落在两个原子中间，就是一条共价键的电子对，按电负性判给一侧。

## 2. 出发点：原有实现的三个问题

项目开始时已有一版可用的实现（本仓库的历史数据 data/v1/ 就是它跑出来的），
判定规则是"贪心法"：对每团电子独立地找它最近的两个原子，谁近（或谁电负性大）
就给谁。我们在评审中发现三个问题：

**问题一：贪心法会给出物理上不可能的答案。**
最典型的是 As4S4（雄黄）：一个硫原子被分到了 14 个电子。硫的价电子层最多
容纳 8 个电子，14 是不可能的。原因是贪心法每团电子独立决策、互相不通气，
恰好有很多团电子都"最近的原子是这个硫"，就全堆给它了。旧代码里有一个补丁
（EOS_O_MAX）专门防止氧超过 8 个电子，但那只保护氧——硫、磷等其他元素
没有保护，而且这种按元素逐个打补丁的路子永远打不完。

**问题二：代码里的另一个分配算法（匈牙利算法分支）有设计缺陷，实际上不可用。**
它给每个原子按"中性原子的电子对数"设置槽位。这意味着阴离子永远拿不到比
中性状态更多的电子——而阴离子的定义恰恰就是拿了更多电子。例如氧要变成
O²⁻ 需要 4 对电子，但槽位只有 3 对。我们检查了全部 198 个历史算例的输入
文件，确认这个分支从未被启用过，于是直接删除。

**问题三：一些理应有的能力实际上不存在。**
代码声称支持"分子动力学轨迹逐帧分析"（EOS_EVERY_N 开关），但主程序的
接线写死了"只在第一步分析"，这个功能从未真正运行过——历史算例全是单点
计算，所以一直没暴露。类似地，代码注释自称遵循 IUPAC 2014 规则，用的
电负性表却是 Pauling 标度，而 IUPAC 官方配套的是 Allen 标度。

## 3. 我们的核心方案：把电子分配变成运输问题

三个问题的共同根源是"每团电子独立决策"。我们的替代方案是让所有电子
**一起**做一次全局决策，数学形式是运筹学里的经典问题——最小费用流
（运输问题）。用朴素的话说：

- 每团 Wannier 电子是一件**货物**（闭壳层时每件装 2 个电子）；
- 每个原子是一个**仓库**，有明确的容量范围——下限是必须装满的部分
  （内层半芯电子），上限是价电子层的物理容量（氧最多 8 个电子，
  这一下就杜绝了"硫拿 14 个"的灾难）；
- 把一件货物运到某个仓库有**运费**：距离越远越贵，仓库主人（原子）的
  电负性越大越便宜；
- 求解"总运费最小"的分配方案。

这样做有三个立竿见影的好处：

1. **有全局最优解**，而且由于货物数量和仓库容量都是整数，最优解自动是
   整数分配——氧化态不需要再做四舍五入。
2. **容量约束天然通用**，不用再按元素打补丁。
3. 数学上是被研究透了的问题，求解快、行为可预期。

后来我们又发现这个框架附带解决了两个原来没想到的问题：

- **幽灵电子**：有时 Wannier 函数的数量比实际占据的电子对多（体系有
  分数占据时会发生），如果假定每团都装满 2 个电子，总电子数就会超过
  真实值。解决办法是给总运输量设一个上限（等于真实电子数 NELECT），
  求解器会优先运"便宜"的货物，多出来的幽灵货物自动被排除。
- **电子丢失**：反过来，有时部分电子没能进入 Wannier 表示（CO 案例丢了
  0.354 个电子），同一个上限机制让分配自动适配实际到手的电子数。

## 4. 关键决策记录

**论文的核心主张选"运输形式化"（而非"工具集成"或"去经验化"）。**
我们检索了文献确认：用 Wannier 中心判氧化态这件事本身有先行工作（Jiang-
Levchenko-Rappe 2012 首创；Gimferrer-Salvador 2020 系统批判过"最近原子
判据"的失效但没给出修复；Comas-Vilà 2025 用另一条重量级路线（QTAIM 原子
重叠矩阵）做了固体版）。而"把电子归属表述为带容量约束的全局运输问题"
检索不到先例，是我们真正的新贡献。因此论文定位是"修复者"：失效模式
前人已诊断，我们给出系统性的治法。

**软件架构采用双路径。**
VASP 内部保留一个修复后的快速贪心（服务分子动力学的原位分析），复杂的
运输求解、诊断和统计放在独立的 pyleos Python 包里做后处理。理由：分配
问题的规模很小（几十到几百个变量），Python 求解只要毫秒级，没有性能
压力；而 Python 侧开发、测试、画图都比 Fortran 快一个量级。算法先在
Python 里定型，将来如有需要再回移 Fortran。

**运费公式（代价函数）分档设计。**
- 档 1：距离的平方 + 电负性折扣。只用 Wannier 中心的几何信息。
- 档 2：再加上"这团电子由哪些原子的轨道构成"的成分信息（从 PAW 投影
  系数算出，随 EOSCAR 的 #WP 数据块导出）。
- 档 3：完整的原子重叠矩阵——这等于走 Comas-Vilà 的重型路线，放弃我们
  的成本优势，故排除。
实际进展：档 1 是当前的生产配置；档 2 的数据管道已打通，但第一版代价
公式失败了（见 RESULTS 的"诚实的负结果"一节），需要重新设计。

**容量约束用"宽物理界"，不用"化学先验"。**
仓库容量按物理极限设置（价层最多装多少），而不是按"化学上常见的氧化态
范围"设置。理由：用已知氧化态范围当约束，等于用答案约束答案（审稿人
会指出循环论证），而且会把高压相、新奇价态这类"发现型"结果在数学上
排除掉。宽物理界只排除不可能，不排除罕见。

**电负性默认用 Allen 标度。**
IUPAC 2014/2016 技术报告配套的是 Allen 标度；旧实现用 Pauling 属于
名实不符。保留 Pauling 作为可选项便于对比。

**三个应用演示。**
- A（Li2O2 脱锂）：锂空气电池的充电过程本质是"过氧化物 O2²⁻ 逐步变成
  超氧 O2⁻"，氧的价态在变而金属价态不变。主流的 DFT+U+V 占据矩阵方法
  只能盯住 d/f 金属位点，对氧的价态无能为力——这正好是 LEOS 的差异化
  主场（阴离子氧化还原）。
- C（CeO2 氧空位）：拔掉一个氧原子会留下两个电子，它们应该落到两个铈
  原子上把 Ce⁴⁺ 变成 Ce³⁺。这是催化领域的标准问题，同时考验 4f 电子的
  Wannier 化（历史上 f 电子是本方法的重灾区）。
- B（富锂正极 + 机器学习势）：规模最大、链路最长，设 2 周时间盒，超期
  降级为展望。

**轨迹模式的"热启动"（warm start）用引导中心实现。**
分子动力学里相邻帧结构变化很小，理论上可以复用上一帧的 Wannier 化结果
加速本帧。wannier90 库接口不支持直接传入初始矩阵，可行的等价物是把上
一帧的中心作为"引导中心"（guiding centres）写进输入。已实现并验证机制
生效；但在小体系上引导本身的开销超过节省（诚实记录），收益要到大体系
难收敛的场景才能兑现。

## 6. 关键文献

- **Comas-Vilà et al., JCTC 2025**（docs/refs/ 有 PDF）："EOS"这个名字的
  出处。他们用 QTAIM 原子域 + 原子重叠矩阵的重型后处理链（四个程序串联）
  做同样的事，测试集 40 个固体。我们的差异：免积分、单程序、快几个量级、
  能做轨迹；他们有可靠性指标 R(%) 和片段分析，我们需给出对应物。他们的
  测试集是我们 M4 的蓝本（data/structures/ 的结构库）。
- **Gimferrer, Comas-Vilà & Salvador, Molecules 2020**：系统论证了"定域
  轨道中心 + 最近原子判据"的失效（会把 O-H、N-H 键错判成氢化物）。我们
  的定位：他们诊断，我们治疗——SrBe(OH)4 等案例的修复直接回应此文。
- **Marzari 组, npj Comput. Mater. 2025**：用 DFT+U+V 占据矩阵沿分子动力
  学追踪氧化态。与我们轨迹能力重叠，但他们只能处理 Hubbard 位点（d/f
  金属），氧的价态是结构性盲区——所以我们的演示 A 选阴离子氧化还原。

### 写作注意：术语歧义

论文里 "transport" 一词对凝聚态读者的第一联想是**电子输运**（电导、迁移率，
Wannier 插值 + 玻尔兹曼方程那条线），与我们的运筹学"运输问题"完全无关。
首次出现处必须显式限定——用 "optimal assignment / minimum-cost-flow
formulation"，或写明 "optimal transport (in the operations-research sense)"。

## 7. 风险与未决事项

1. **档 2 代价公式重设计**：第一版失败（重原子的投影权重天然偏大，把
   电子系统性拽向重原子）。候选方向：按原子基线归一、或只在几何模糊时
   介入当裁决者。
2. **补丁的正式合并**：当前 v3 = v2 补丁 + patch/v3/ 的覆盖文件与注入
   脚本，尚未合并成单一 diff 文件。
3. **极化子局域化**：PBE 泛函下空穴/电荷序离域是已知的自相互作用误差，
   影响 Li2O2 空穴和 Fe3O4 电荷序的"位点级"判定（元素级不受影响）。
   需要对称破缺的初始猜测 + U 或杂化泛函。
4. **离域多中心键**：三碘化物 I3⁻、金属簇 WAu12 这类体系是"每团电子
   归一两个原子"图像的原理性极限，需要片段（fragment）功能。
5. **M5-B 尚未建模**；warm start 的大体系收益基准未做。
