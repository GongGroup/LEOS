# WCL6 — 三方 R-3 α-WCl6 完整六方胞(21 原子)

- 相:α-WCl6 分子晶体,空间群 R-3 (No. 148),六方设置,Z=3(与 Materials Project
  mp-571518 同相;登记表 known_phase 一致)。
- 晶格:沿用测试集现有胞(data/v3/comas_gap/scdm_wcl6 与 data/v3/m4_wave2/wcl6,逐字节相同):
  a = 6.2356 Å, c = 17.0110 Å(实验值 6.088/16.68,现有胞约 +2%,登记表判定"晶格是对的")。
- 原子坐标:W 3a (0,0,0);Cl 18f (0.295, 0.295, 0.08),取自实验 CIF
  COD 1537510(Ketelaar & van Oosterhout, Recl. Trav. Chim. Pays-Bas **62**, 197 (1943),
  = ICSD 26081),按 R-3 全部 18 个对称操作展开成完整六方胞。
- 为何不用现有 POSCAR 的 Cl 坐标:现有 2 原子胞的 Cl 相对标准 18f 轨道漂移约 0.98 Å
  (2 原子残胞被弛豫过的痕迹),直接展开会得到畸变八面体;故 Cl 采用实验坐标。
  现有 W 位置与 3a 的偏差同样是漂移(约 1.6 Å),展开时以标准原点为准。
- 自检:计量 W3Cl18 = 3×WCl6 ✓;每个 W 恰好 6 个 Cl 配位,W-Cl = 2.288 Å
  (实验 2.24-2.29 Å,在现有略胀的胞中为 2.29 Å)✓;任意两原子距离 ≥ 2.288 Å > 1.5 Å ✓。
- 适用案例:wcl6(m4_wave2)与 scdm_wcl6(comas)。压力:常压实验相。
