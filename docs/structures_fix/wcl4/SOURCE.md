# WCL4 — 单斜 C2/m (WCl4)x 链状聚合物完整胞(20 原子)

- 相:β-WCl4(NbCl4 型共棱八面体一维链,链内 W-W 交替成对),空间群 C2/m (No. 12);
  实验结构 Kolesnichenko, Swenson & Messerle, *Inorg. Chem.* **37**, 3257 (1998),
  DOI 10.1021/ic9801286(= COD 6000616 晶格条目 / ICSD 165263;Comas-Vilà 对照集
  编号 12 所引 CCDC 1681327 即此测定)。实验胞 a=11.782, b=6.475, c=8.062 Å, β=131.14°。
- 晶格:沿用测试集现有胞(a=12.186, b=6.467, c=8.289 Å, β=130.82°,登记表判定与实验胞吻合)。
- 原子坐标:由现有 POSCAR 的 4 原子不对称单元按 C2/m 的 8 个对称操作自行展开:
  W 4g (0, 0.7960, 0)(贴齐量 0.104 Å);Cl 4i (0.6802, 0, 0.1548)(贴齐 0.006 Å);
  Cl 4i' (0.6985, 1/2, 0.1693)(贴齐 0.015 Å);Cl 8j (0.0244, 0.7635, 0.2904)。
  贴齐指把偏离特殊位置 <0.11 Å 的坐标压回 Wyckoff 约束(残余噪声来自当年 4 原子残胞的弛豫)。
- 交叉验证:AFLOW ICSD_WEB 条目 Cl4W1_ICSD_165263(同一实验结构的 PBE 弛豫版)
  惯用胞同为 C2/m、W4Cl16;本展开的轨道类型(W 4g + Cl 4i×2 + Cl 8j)与其一致。
- 自检:计量 W4Cl16 = 4×WCl4 ✓;每个 W 六配位,W-Cl = 2.234-2.540 Å ✓
  (2.2-2.4 指引内,桥 Cl 略长属正常);链内 W-W = 2.638 / 3.829 Å 交替
  (d2-d2 金属键成对,实验约 2.69/3.79 Å)✓;最短原子间距 2.234 Å > 1.5 Å ✓。
- 适用案例:wcl4(m4_wave2)与 scdm_wcl4(comas)。压力:常压实验相。
