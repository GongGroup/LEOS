# LEOS 阶段性成果整理（2026-07-07，M1-M3 完成）

对应代码：pyleos/（分配与分析）、patch/leos.patch + patch/v3/（VASP 侧）、
生产 build `sai-pod:~/apps/vasp.6.4.3_leos_v2/bin/`。

## 一、改进清单及原因

### A. 分配算法（pyleos，论文核心主张）

| # | 改进 | 原因（含实证） |
|---|------|----------------|
| A1 | 容量约束最小费用流（运输形式化）替代最近邻贪心 | 贪心的两中心假设加逐元素补丁（EOS_O_MAX 只保护氧）不可扩展：As4S4 中 S 被分到 13-14 电子（OS=−7/−8，超出价层物理容量）；文献先例（Gimferrer 2020）已证最近原子判据系统性失效但无人给出修复 |
| A2 | 删除 Fortran 匈牙利分支 | 结构性设计错误：槽位数按中性原子设定（ATOM_CAP=ZVALF/RSPIN），阴离子在完美匹配下永远拿不到超中性电子（O(−2) 需 4 对但只有 3 槽），闭壳层体系退化为全零氧化态；198 个历史算例的 INCAR 无一启用过该分支 |
| A3 | 宽物理容量界（价壳上限）+ 半芯 n_min 下界 | 容量只排除物理不可能（防 A1 的灾难），不编码化学先验（避免循环论证、保留新奇价态发现能力）；半芯壳层（如 Na_pv 的 2s2p）必须满占据，用负代价边段强制 |
| A4 | 总流量以 NELECT(Wannier) 为上限的最小费用 k-流 | num_wann 超出占据流形时满占据假定注入幽灵电子（li2o2：9 WF 供 18e 而 NELECT=14）；SSP 按最短路顺序推流，幽灵 WF 路径最贵自动出局；同一机制吸收电子丢失案例（CO 的 dNe=0.354），一处设计双重收益 |
| A5 | Allen 电负性为默认标度（Pauling 可选回退） | 原实现自称 IUPAC(2014) 规则却硬编码 Pauling 表；IUPAC 2014/2016 技术报告配套的是 Allen 标度，对 H 与过渡金属排序有实质差异（CSe2 判定方向依赖标度） |
| A6 | 电负性权重 β 默认 10 | β 扫描定位 X-H 键的翻转点在 6-10（键 WF 中心几何偏向 H，需要足够的电负性项压回），β∈[10,15] 平台稳定、36 案例无副作用 |
| A7 | stray WF 检测 + `--drop-stray` 归因模式 | 把"分配算法的误差"与"Wannier 化质量的误差"解耦定责（As4S4 定责实验的工具化）；阈值 spread>3 Å² 或中心离全部原子 >1.6 Å（1.6 为放过同核键中点，As-As/2=1.28） |

### B. VASP Fortran 侧（patch v2 → v3）

| # | 改进 | 原因（含实证） |
|---|------|----------------|
| B1 | (spin,k,band) 级电子丢失诊断（N_LOST_* 进 OUTCAR/EOSCAR 头） | 占据带落在冻结窗外时电子无声丢失、只报总量 dNe：CO 案例（带交叉+分数占据 0.864，占据带数 19-21 随 k 波动）的根因先前不可见 |
| B2 | EOSCAR v2：#WF 明细块（占据/中心/spread/贪心归属） | pyleos 运输分配的输入数据；也是结果可解释性的基础（As4S4 排查靠的就是这层数据） |
| B3 | #WP 投影权重块：每 WF 的原子投影仪范数指纹 | 档 2 运输代价需要"这对电子由谁的轨道构成"（中心几何的互补信息，对坏 WF 仍有效）；首版 QION 增广差加权实测失败——软赝化通道（O 2p）增广差趋零，孤对对比度仅 1.35:1，改纯投影范数后恢复 ~5:1 |
| B4 | EOS_SCDM_ONLY 快速模式（num_iter=0/dis_num_iter=0 注入 win） | 检验"氧化态判定是否需要完整 MLWF 最小化"的效率假设 |
| B5 | EOS_WARM_START：上一步 WF 中心注入为 wannier90 guiding centres | 轨迹模式逐帧从头 Wannier 化浪费；库模式无 U 矩阵热启动接口，guiding centres 是可行的等价物 |
| B6 | main.F 轨迹钩子重写（EOS_DO_THIS_STEP 逐步执行） | 重大发现：生产树的老集成写死 `IF (NSTEP == 1)`，EOS_EVERY_N 轨迹特性在 v1/v2 中从未真正执行（历史算例全为单点计算故未暴露）；顺带修复每步无条件 MLWF_FREE 但仅首步重建的悬空引用隐患 |
| B7 | 杂项修复 | 周期回卷 MOD(x+60,1)→x−FLOOR(x)（长 MD 越界）；自动窗口 GAP_TOL 1e-3→5e-2 eV（原值为数值噪声量级）；main.F TAB 缩进清理；Allen 表镧锕系回退 Pauling 值 |

### C. 求解器工程（pyleos）

| # | 改进 | 原因（含实证） |
|---|------|----------------|
| C1 | SSP 势更新覆盖不可达节点（Johnson 标准处理） | 遗漏时节点重新可达携带过期势 → 负 reduced cost → Dijkstra 指数退化（首次全量回归挂死近 6 小时的根因） |
| C2 | n_min 奖励常数 1e5→1e3、容差 1e-12→1e-9 | 1e5 量级的势与距离相减后舍入残渣 ~1e-11 与 1e-12 容差同阶，被判为假改进 → 堆无限重推（CH2F2 是首个触发 F 的 n_min=7 负边的案例，精准定位） |
| C3 | 增广轮数上限防御 | 任何未来的终止性 bug 抛异常被回归框架捕获标记，不再无声挂死 |

## 三、结果

### 3.1 回归总表（β=10，Allen，宽容量）

| 指标 | 数值 |
|---|---|
| 元素级氧化态与理想值一致（dev≤0.25） | **33 / 36** |
| 运输优于现行贪心 / 劣于 | **6 / 1**（劣项 CSe2 为输出截断的坏数据） |
| 全量回归耗时（纯 Python 求解器） | ~30 秒 |

修复历程参照：初版 13/36（劣 16）→ 幽灵电子修复后 29/36 → β=10 后 33/36。

### 3.2 标志性案例（最大元素级偏差，运输 vs 贪心）

| 案例 | 运输 | 贪心 | 说明 |
|---|---|---|---|
| As4S4 | 1.00 | 2.12 | 容量约束拦住 S 收 14e 的灾难；剩余偏差全部可归因（见 3.3） |
| CO（dNe=0.354） | **0.00** | 0.25 | NELECT 上限流对电子丢失免疫 |
| ReO3 / reo3（金属） | **0.00** | 2.00 | 金属案例贪心失效、运输全对 |
| Li2O2（过氧化物） | **0.00** | 1.00 | O 均值 −1 正确（阴离子氧化还原能力的静态佐证） |
| ReF6 | **0.00** | 1.00 | F 的 n_min=7 半芯约束生效 |
| CH2F2 | 0.00（β≥10） | 0.00 | X-H 键翻转点实证（β=3/6 时运输 dev=4.00） |

### 3.3 As4S4 定责实验（`--drop-stray`）

- 88 个 WF 中 15 个未定域化（spread 最大 22.6 Å²，中心悬在结构空洞）
- 全量分配：As 侧多收 16e（64 vs 理想 48）→ 元素均值偏差恰为 1.00
- 剔除 stray 后 73 个化学可解释 WF：S 得 110/110、As 得 36/36，**逐电子零误差**（含 27 个 As-S 键电子全部判给电负性大的 S、6 个 As-As 同核键正确留在 As）
- 结论：干净输入上分配零误差；误差全部可追溯到可检测的输入缺陷 → 有界退化 + 自我诊断 + 修复路径唯一（重跑 Wannier 化）

### 3.4 效率（sai-pod 实测）

| 项 | 数据 |
|---|---|
| SCDM-only vs 全 MLWF（CO2） | 氧化态**完全一致**；wannier90 时间 2 s → 0.023 s（**~86×**） |
| 并行编译（make DEPS=1 -j8） | 全量 5-8 分钟（串行 >1 小时） |
| warm start（3 步 CO2 MD） | 机制生效（第 2 步起 win 含 guiding_centres + 40 投影行）；小体系开销>收益（0.58→1.3 s），目标场景为大体系难收敛案例，待基准 |

### 3.5 轨迹模式（v3 首次真正落地）

- 3 步 92K CO2 MD：EOSCAR 输出 STEP 1/2/3 完整逐步分析（v1/v2 因 main.F 写死 NSTEP==1 从未做到）
- **新素材**：贪心氧化态沿轨迹漂移（C +4 → 第 3 步 +3/+2，92K 下物理不可能）——朴素贪心轨迹不稳定的直接实证，运输后处理的价值打点
- MD 中 num_wann 随分数占据虚胖（32→40），pyleos 的 NELECT 上限流自动排除

### 3.6 数据质量基线

- CO2 电子守恒：|dNe| = 9.6×10⁻¹¹（机器精度）；N_LOST=0
- #WP 指纹：孤对 top-1 权重 ~0.58（对比度 ~5:1）、键 WF 呈 C/O 双成分（0.81/0.55）——键极性的直接轨道证据
