### 2. 任务二 OOM 取证闭环：Ce18O36Co4CH4 六次失败根因定性

六次失败全部为主机内存 cgroup 杀（sacct 状态 OUT_OF_MEMORY），发生在启动后
16-21 秒的初始化分配段；实测 RSS 随 rank 数近线性增长（4 rank 56.2 GB 险过 →
8 rank 106.7 GB）。根因三件套：① ALGO=ALL 持有三份波函数（8.39 GB/rank）；
② FS/TS 的 INCAR 写了 KPAR=2——KPAR 并不切分 k 点存储，反而使每 rank 注册量
升到 18.9 GB（IS 是 KPAR=1，所以 4 GPU 险过）；③ SCDM 在 rank0 的双缓冲峰值
10.8 GB。WAVECAR 假说证伪（LWAVE=F、文件 0 字节）。零代码修复方案
（KPAR=1 + NBANDS=308 + 补 MAGMOM）预计 4 GPU 从容通过。模型与 VASP rank0
自报 10.2 GB 对账，误差 <2%。

- 产出：`docs/reports/20260710_mem_root_cause.md`
- 遗留：零代码配置的 4 GPU 实测未做（归入服务器批次）。

### 3. GPU 化决策链：grill 五问 + 双 agent 探索

想法阶段先做评估：场景为 MD 轨迹逐帧 + 未来大体系，收益按墙钟/机时/吞吐三个
维度全要，A（自建工具）/B（fork wannier90）两路都评估，物理等价为验收口径。
探索结论是"可行但不该先做"：Ce 单点的 GPU 只覆盖 SCF 段（约 77% 墙钟），SCF
之后 8×V100 闲置 3775 秒（约 23%）；wannier90 库模式段 2817 秒纯单核（参考
实现无线程 BLAS、两自旋顺序执行，其中 spin2 disentanglement 打满 1000 迭代
不收敛烧掉 1743 秒）；GPU 化的现实加速仅 5-15 倍（矩阵 250-350 维喂不饱
V100，batch 维度只有 nk）；零代码替代（离线 w90.x MPI + 两自旋并发）即可拿到
6-20 倍，覆盖期望收益；社区零前例（wannier90 无 GPU 分支、QE 仅 MPI、
EPW/Perturbo 只 GPU 化消费端）。老大拍板：CPU 优化包与 GPU 独立工具并行立项。

- 产出：`docs/reports/20260710_gpu_exec_map.md`、
  `docs/reports/20260710_gpu_feasibility.md`
- 遗留：CPU 优化包两项（离线 w90 MPI 工作流、dis 不收敛调查）未开工。
